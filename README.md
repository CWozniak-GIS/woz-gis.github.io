# woz-gis.github.io

This repository contains the source for my personal site: https://woz-gis.com

Right now, the site serves as a simple portfolio hub — a central place to share links to projects, work, and other GIS-related content. It’s intentionally minimal, with a bit of styled CSS to give it some visual character.


## Current Features:
- Quick access to project links and external resources
- Lightweight, static site design
- A touch of custom CSS for presentation


## Future Plans
This site may eventually evolve into a more complete portfolio, with projects hosted and showcased directly within the site itself. For now, it remains a simple, clean landing page.
